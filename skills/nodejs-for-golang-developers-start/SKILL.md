以仓库根目录的 [README](../../README.md) 为启动命令的唯一来源。

- 找到包含本技能的仓库，检查 Node、npm、Go 和已有服务。遵守仓库内的 AGENTS.md。
- 依赖缺失时按 README 安装；构建页面并启动服务。记录本次服务 PID、日志位置和监听端口；不要重复启动，也不要结束未知进程。
- 默认 localhost。用户需要远程访问时使用 HOST=0.0.0.0 和指定 PORT，未设置 ACCESS_TOKEN 时服务自动生成令牌并打印私密访问链接；需要固定令牌时才设置 ACCESS_TOKEN。在私密渠道交付链接，启动日志包含令牌，不要写入共享日志或仓库。告知实际机器地址，不能把 0.0.0.0 当作可点击地址。无可信网络时优先用 README 的 SSH 转发方式。
- 请求 /api/config 验证服务已启动，然后给出浏览器地址、访问方式和仅停止本次进程的方法。无法确认外部网络可达时如实说明，不声称已验证公网访问。
- 启动任务不需要执行学习代码或运行完整测试。遇到端口冲突换一个可用端口；依赖或构建失败时修复明确原因，涉及系统权限、凭据或外部防火墙则说明具体阻塞。

仅负责启动。主题内容、编辑器、代码运行与进度由应用自身管理。
